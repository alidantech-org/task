# Everyday task experience goal

## Goal
Make the daily use of Task pleasant and powerful for people and agents. The board and calendar must show the right group on every task, remember how the user left them, and let tasks be reordered by dragging so the order is part of the task data. Tasks need the building blocks teams expect from Asana or Jira: comments with authors and mentions, subtasks and typed relations, editable properties, filters and saved views, bulk actions, an activity timeline, templates, recurring work and small attachments.

## Success criteria
- Every card and row shows its group name, including finished groups.
- Refreshing the page keeps the board or list view, filters, calendar mode and order of tasks.
- A task can be reordered by dragging, from the command line and by the API, and the order persists in the task file.
- Comments, subtasks, links, watchers, attachments and recurrence can be managed from the dashboard and from the command line.
- Day and week sheets let a user manage everything scheduled for that day or week.

## Scope
In scope: the workspace package, command line, local runtime and dashboard. Out of scope: server-side storage for large files, email or push notifications, and user accounts.
